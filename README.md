# 🎬 База фильмов

**Учебная конфигурация на платформе 1С:Предприятие 8.3** — удобный каталог для хранения фильмов: жанры, актёрский состав, оценки и поиск по жанрам.

Разрабатывается в [1C:EDT](https://edt.1c.ru/) 2025.2, исходники хранятся в Git, изменения синхронизируются с информационной базой прямо из среды.

---

## ✨ Возможности

- 📽️ Каталог фильмов с датой выхода, описанием и иностранным названием
- 🎭 Актёрский состав — табличная часть с ролями
- 🎨 Жанры — табличная часть + автоматическая строка «жанров для поиска» (собирается в `ПередЗаписью`)
- ⭐ Оценка фильма с контролем диапазона (не больше 10)
- 🔍 Поиск по строке жанров
- 🗂 Разделение фильмов по видам: Фильм / Сериал / Мультфильм / Мульт3Д

## 🗂 Структура конфигурации

| Объект | Тип | Назначение |
|--------|-----|------------|
| **Фильмы** | Справочник | Главный каталог: дата выхода, тип, оценка, описание, иностранное наименование |
| **Актеры** | Справочник | Актёры, участвующие в фильмах |
| **Жанры** | Справочник | Справочник жанров |
| **Вид** | Перечисление | Фильм / Сериал / Мультфильм / Мульт3Д |
| **Жанры** | Перечисление | 13 жанров: от комедии до фэнтези |
| **АктерскийСостав** | Табличная часть Фильмов | Кто играет в фильме |
| **Жанры** (ТЧ) | Табличная часть Фильмов | Жанры фильма, формируют строку поиска |
| **ПолныеПрава** | Роль | Полный доступ ко всем объектам |
| **Фильмы** | Подсистема | Ключевые объекты конфигурации |

## 🚀 Как открыть проект

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Sonata-Girl/films_EDT.git
   ```
2. В 1C:EDT: **Файл → Импорт → Общие → Существующие проекты в рабочую область** → укажите папку проекта
3. Свяжите с информационной базой и запускайте через ▶ — конфигурация синхронизируется автоматически

## 🌿 Ветки

- `dev/task_N` — разработка задач
